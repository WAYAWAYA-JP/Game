---

## 背景と目的

戦闘中に開くスキルウィンドウ・魔法ウィンドウのリストには、スキル名・コスト・威力などの数値は表示されているが、  
「どういう操作で発動するか」「どんな効果か」の説明文が表示されていなかった。

本設計書では以下を目的とする：

1. **スキル・魔法のリストに効果説明文（description）を表示する**
2. UIは既にスケルトンが存在する（2カラム構造）ため、**JSONデータに `description` を追加するだけで完結**
3. アイテムについては将来対応（スコープ外）

---

## UIレイアウト（変更前から実装済み）

`skill_window.gd` と `magic_window.gd` は既に **2カラム（HSplitContainer）構造** が完成している。

```
┌────────────────────────────────────────────────────┐
│  [左カラム] スキル/魔法一覧    │  [右カラム] 詳細   │
│                                │                    │
│  ▶ シングルクリック            │  ■ シングルクリック │
│    ダブルクリック              │  種別: 攻撃スキル   │
│    トリプルクリック            │  SP: 0             │
│    右クリック                  │  威力: 1.0         │
│    ...                         │  ───────────────   │
│                                │  マウスを一度クリ  │
│  [全て][攻撃][防御][上級]      │  ックして攻撃する。│
│                                │  SP消費ゼロで...   │
└────────────────────────────────────────────────────┘
```

**重要**: 左のリストでスキルを選択すると右カラムに詳細が表示される仕組みは既に存在する。  
`SkillDetailPanel.show_skill()` / `MagicDetailPanel.show_spell()` が `description` キーを参照しているが、  
JSONに値がなかったため空欄になっていた。

## データ形式

### skills.json — フィールド追加例

```json
{
  "id": "single_click",
  "name": "シングルクリック",
  "description": "マウスを一度クリックして敵を攻撃する、すべての操作の基本。SP消費ゼロで使い放題。",
  "input_type": "click",
  "sp_cost": 0,
  "power_ratio": 1.0,
  "unlock_level": 1
}
```

### spells.json — フィールド追加例

```json
{
  "id": "select",
  "name": "セレクト",
  "description": "選択コマンドを魔術化した呪文。対象を捕捉し魔法ダメージを与える。INT依存で威力が上がる。",
  "mp_cost": 5,
  "power_ratio": 1.2,
  "category": "offensive"
}
```

## 技術メモ

### なぜUIコードを変更しないか

`skill_window.gd` の `_load_skills()` は既に `description` を取り出す実装が存在する：

```gdscript
var skill_data: Dictionary = {
    "id":          skill_id,
    "name":        skill.skill_name,
    "description": skill.description,  # ← SkillBase.description を取得
    "sp_cost":     skill.sp_cost,
    ...
}
```

`SkillDetailPanel.show_skill()` も:

```gdscript
_desc_label.text = skill_data.get("description", "")
```

として実装済み。**JSONに値を追加するだけで自動的に表示される。**

`magic_window.gd` も同様の構造。

## 検証方法

2. SKLボタンからスキルウィンドウを開く
3. 各スキルをクリック → 右カラムにdescriptionが表示されることを確認

5. 各呪文をクリック → 右カラムにdescriptionが表示されることを確認
